`React` `Vite` `Node.js` `Express` `PostgreSQL`

`JWT` `Google OAuth` `Multer` `Nodemailer` `Railway`

* 📅 Gestión de horarios

* 📄 Gestión de documentos
* 📧 Notificaciones por correo
* 👨‍💼 Panel administrativo
* 🗄️ Base de datos PostgreSQL
* 🌐 API REST
* ☁️ Despliegue del backend
