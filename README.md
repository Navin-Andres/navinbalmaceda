## 🚀 Proyectos destacados

### ⚖️ Consultorio Jurídico

Sistema web para la gestión de estudiantes, matrículas, cupos, turnos y documentos.

**Tecnologías:**

`React` · `Node.js` · `Express` · `PostgreSQL` · `JWT` · `Google OAuth` · `Multer` · `Nodemailer`

**Características:**

- Gestión de matrículas y cupos
- Administración de estudiantes
- Gestión de documentos
- Autenticación y autorización
- APIs REST
- Panel administrativo
- Gestión de turnos
- Despliegue en la nube

---

### ⚽ La Jugada

Aplicación web para la **reserva de canchas de fútbol**.

**Características:**

- Reserva mediante enlace o código QR
- Control de disponibilidad
- Gestión de comprobantes de pago
- Bloqueo temporal de reservas pendientes
- Gestión de información de las reservas

---

### ♻️ Ecovalle — Gestión de Residuos

Aplicación orientada a la gestión de residuos, incorporando información geográfica y evidencia fotográfica.

**Características:**

- Registro y gestión de residuos
- Captura de fotografías
- Ubicación geográfica
- Consulta y seguimiento de información
